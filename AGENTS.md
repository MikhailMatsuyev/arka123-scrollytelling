ARKA 123 — AI Agent Instructions

Project

This repository contains a test assignment for a Vibe Coder position.

Brand: АРКА 123
Business: rental of a 123 m² space for workshops, seminars and other events.
Slogan: «Встречаемся напротив Библиотеки.»

The key visual feature of the space is the large arched windows (4 × 3.5 m) with a view of the National Library of Belarus.

Scope

The original test assignment contains 5 parts:

Logo animation

Brand character

3D / 360° / video presentation of the space

Brand hero + scroll-driven animation

Complete website

Our scope

We implement only Task №4.

However, Task №4 must be designed as a component of the future ARKA 123 website and must respect the visual identity, architecture and concept described in the complete assignment.

Do not implement unrelated parts of the assignment unless they are required to support Task №4.

Task №4 Goal

Create a brand hero who presents the ARKA 123 space.

The animation must:

present the space and its atmosphere;

show the distinctive arched windows and the view of the National Library;

work as a visual background / hero scene;

be controlled by page scrolling;

be suitable for integration into a commercial website;

preserve the real architecture and proportions of the space;

look like one coherent visual experience rather than a collection of unrelated AI-generated assets.

The exact visual concept is open and should be developed during the project.

AI / Generation Constraints

The test assignment allows AI tools, but this implementation should be designed around free tiers / free tools whenever possible.

Do not introduce a paid AI dependency unless explicitly approved.

AI-generated assets should be created with consistency in:

character appearance;

environment;

lighting;

architecture;

visual style;

composition.

Prefer generating a limited number of high-quality keyframes/assets and creating motion in the browser rather than relying on long AI-generated video.

Technical Direction

The implementation should favor:

modern frontend architecture;

smooth scroll-driven animation;

good performance;

responsive behavior;

maintainable code;

minimal unnecessary dependencies.

Possible technologies include:

TypeScript

React / Vite

GSAP / ScrollTrigger

Canvas

image sequences

CSS animation

Web APIs

The final technology choice must be based on the actual visual solution rather than being predetermined.

Do not add libraries without a clear reason.

Architecture / Visual Integrity

The supplied ARKA 123 materials are the source of truth for the real space.

Do not significantly distort:

room geometry;

window proportions;

architectural elements;

layout;

perspective.

Creative visual effects are allowed, but the space must remain recognizable as the actual ARKA 123 location.

Development Rules

Keep implementation simple and understandable.

Prefer small, focused components/modules.

Avoid premature abstractions.

Avoid unnecessary configuration.

Do not add functionality that is not required by the current task.

Keep performance in mind, especially for scroll-driven animation and large media assets.

Test the animation on desktop and mobile viewport sizes.

Do not hard-code values that should obviously be configurable.

Git

The user controls GitHub manually.

The AI assistant must not:

push to GitHub;

create commits;

modify remote repositories;

create pull requests;

change branches remotely.

The user will review changes and perform Git operations manually.

Working Style

Before making significant implementation decisions:

Check the current project files.

Check PLAN.md.

Prefer the simplest solution that achieves the required visual result.

Explain important architectural decisions briefly.

Do not rewrite working code unnecessarily.

The primary goal is not to demonstrate the maximum number of technologies.

The primary goal is to produce a commercially convincing Task №4 result for ARKA 123.
